# Smart Talent Intelligence

## Overview
Smart Talent Intelligence is a Multi-Agent AI Career & Learning Platform that helps students and professionals with career guidance, resume analysis, personalized learning, job matching, and AI-powered interview preparation.

## Features
- AI Career Mentor
- Resume Analyzer
- Skill Gap Analysis
- Learning Roadmap
- AI Mock Interview
- Job Matching
- Progress Tracking

## Tech Stack
### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- PostgreSQL

### AI
- Gemini API
- LangGraph
